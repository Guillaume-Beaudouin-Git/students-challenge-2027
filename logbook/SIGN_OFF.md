# Sign-off

An entry belongs to its owner, an objection to its challenger, and a page of the application file
to the member whose name it carries. Before the file is sent, each of us reads those texts, corrects
them and agrees to defend them.

Approvals are given in writing, in the team's group chat. The chair records each one below with its
date. A line without a date means: not approved yet.
